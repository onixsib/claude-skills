# drawio_builder: методы

Все координаты — в пикселях холста, начало в левом верхнем углу. Методы, создающие ячейку, возвращают объект `Cell` с полями `x`, `y`, `width`, `height` и свойствами `right`, `bottom`, `center` — по ним удобно ставить соседние блоки.

Геометрию ячейки можно менять до `save()`: файл пишется по состоянию на момент записи. Так сдвигают блок на ось соседа или растягивают панель на ширину схемы. Стрелки с автоматическим выбором сторон считают точки в момент вызова `arrow()`, поэтому сначала расставь и выровняй блоки, потом проводи стрелки.

## Diagram

```python
d = Diagram("Имя листа")
```

| Метод | Что делает |
| --- | --- |
| `d.box(title, lines=(), *, x, y, width, height=None, kind="plain", dashed=False, title_size=12, line_size=11)` | Блок: жирный заголовок и строки. Без `height` высота подбирается под текст |
| `d.frame(title, *, x, y, width, height, kind="muted", dashed=False, stroke_width=1, filled=True)` | Рамка с явными размерами: полоса, панель. `filled=False` — только цветная обводка |
| `d.frame_around(title, cells, *, pad=18, top_pad=40, kind="muted", dashed=False, stroke_width=1, filled=True)` | Рамка вокруг готовых ячеек: размер считается по ним, слой — под ними |
| `d.note(title, lines=(), *, x, y, width, height=None)` | Жёлтый стикер: пояснение, легенда, вывод |
| `d.text(title, lines=(), *, x, y, width, height=None, title_size=16, line_size=12)` | Текст без рамки: заголовок схемы |
| `d.equal_heights(*cells)` | Выравнивает высоту блоков по самому высокому. Вызывать до расстановки того, что ниже, и до `frame_around()` |
| `d.align_middle(reference, *cells)` | Ставит блоки по вертикали на ось `reference` (центр к центру) |
| `d.arrow(source, target, label="", *, dashed=False, exit=None, entry=None, color=None, font_size=10)` | Стрелка между ячейками |
| `d.arrow_from_point((x, y), target, label="", *, dashed=True, entry=(0.5, 1), color=None)` | Стрелка из свободной точки в ячейку |
| `d.badge(label, *, x, y, kind="open")` | Кружок с номером в произвольном месте |
| `d.badge_on(cell, label, *, kind="open", corner="top-right", index=0)` | Кружок на углу блока (`top-right`, `top-left`, `bottom-right`, `bottom-left`); `index` сдвигает второй и следующие |
| `d.badge_between(source, target, label, *, kind="open", offset=(0, -20))` | Кружок у стрелки между двумя ячейками: развилка про связь, а не про блок |
| `d.card(number, title, lines=(), *, x, y, width, height=None, kind="highlight", badge_kind="open", title_size=13, line_size=12)` | Карточка развилки: блок с вариантами и кружок с номером |
| `d.lint()` | Список предупреждений о раскладке (строки) |
| `d.size()` | Размер холста `(ширина, высота)` по крайним ячейкам |
| `d.save(path)` | Пишет `.drawio`, существующий файл перезаписывает |

## Виды блоков (`kind`)

| Вид | Заливка | Для чего |
| --- | --- | --- |
| `plain` | белая | обычный блок |
| `muted` | светло-серая | второстепенное, справочное, отложенное |
| `green`, `blue`, `purple`, `red` | цветная | роли компонентов; какая роль у цвета — решает схема и записывает в легенду |
| `highlight` | оранжевая | то, на что надо обратить внимание: зависит от развилки, меняется |

`dashed=True` — пунктирная обводка. Что она значит (необязательное, планируемое, под вопросом), решает схема и записывает в легенду; смысл должен быть один.

## Виды кружков (`kind` у `badge`, `badge_kind` у `card`)

| Вид | Цвет | Смысл |
| --- | --- | --- |
| `open` | оранжевый | надо выбрать |
| `deferred` | серый | отложено |
| `done` | зелёный | решено |

## Точки стрелок

`exit` и `entry` — пара долей `(x, y)` на прямоугольнике блока:

```text
(0,0)────(0.5,0)────(1,0)
  │                   │
(0,0.5)            (1,0.5)
  │                   │
(0,1)────(0.5,1)────(1,1)
```

Без `exit`/`entry` стороны выбираются по взаимному положению блоков, а точки — на общей части сторон, чтобы линия была прямой.

## Оценка текста

```python
from drawio_builder import text_height
height = text_height("Заголовок", ["строка", "ещё строка"], width=260)
```

Возвращает высоту блока под текст. Обычно она не нужна: блоки берут высоту сами, рамки ставятся через `frame_around()`. Пригодится, когда надо заранее знать, сколько места займёт колонка. Оценка с запасом: ширина символов берётся усреднённой. Для карточек передавай их кегли: `title_size=13, line_size=12` (константы `CARD_TITLE_SIZE`, `CARD_LINE_SIZE`).

## Что проверяет `lint()`

1. Текст не помещается в блок с высотой, заданной вручную.
2. Два блока пересекаются (вложение одного в другой ошибкой не считается).
3. Блок пересекает границу рамки.
4. Подпись рамки шире самой рамки.
5. Подпись стрелки шире промежутка между блоками, стоящими в ряд.
6. Прямая стрелка проходит сквозь посторонний блок.

Кружки и текст без рамки в проверках не участвуют. Стрелки с изгибом на пересечения не проверяются — их маршрут прокладывает draw.io. Подпись стрелки, наехавшую на границу чужой рамки, проверка тоже не видит. Всё это смотри на рендере.

## Чего в библиотеке нет

Нестандартные фигуры (цилиндры, облака, значки), несколько листов, группировка ячеек в draw.io, кривые стрелки. Если без этого не обойтись, допиши стиль рядом по образцу `_box_style` — формат стилей draw.io это строка `ключ=значение;`.
